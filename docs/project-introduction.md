# CC-Island 项目介绍

## 项目概述

CC-Island 是一个类似 macos 灵动岛的跨平台桌面应用，专为 Claude Code 用户设计。它提供始终置顶的灵动岛 UI，实时监控和管理多个 Claude Code 终端实例，支持权限请求远程响应、问题回答、终端窗口跳转等功能。

**一句话定位**：让 Claude Code 的权限审批和状态监控从「终端内」走向「桌面灵动岛」。

---

### 3. 远程审批流（Mobile → Cloud → Desktop → Claude）

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│  Mobile      │      │  Cloud       │      │  Desktop     │      │  Claude      │
│  用户点击    │─────►│  Server      │─────►│  HTTP        │─────►│  Code        │
│  Allow/Deny  │      │  路由响应    │      │  返回决策    │      │  继续执行    │
└──────────────┘      └──────────────┘      └──────────────┘      └──────────────┘

流程步骤：
1. Mobile 用户点击 Allow/Deny
2. Cloud Server 路由到对应 Desktop
3. Desktop 从 Popup Queue 取出弹窗
4. Desktop HTTP Server 返回决策给 Claude
5. Claude Code 工具继续执行或拒绝
```

## Claude Channels 集成架构

### 集成目的：向 Claude 会话写入内容

**核心目标**：让 CC-Island 可以**主动向 Claude Code 会话写入内容**，而不是仅仅被动接收 Hook。

## 方案对比：Channel vs PTY Wrapper

**核心目标相同**：向 Claude Code 会话写入内容，让 Claude 响应外部事件。

两种方案的技术路径完全不同，各有优劣。

### 方案架构对比

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    Channel 方案                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌──────────────┐                                                           │
│  │  外部事件    │  CI 结果、监控告警、用户指令                             │
│  │  来源        │                                                           │
│  └──────────────┘                                                           │
│          │                                                                  │
│          ▼                                                                  │
│  ┌──────────────┐                                                           │
│  │  CC-Island   │  格式化内容，发送 notification                            │
│  │  Desktop     │                                                           │
│  └──────────────┘                                                           │
│          │                                                                  │
│          ▼                                                                  │
│  ┌──────────────┐      ┌──────────────┐                                    │
│  │  Channel MCP │◄────►│  Claude Code │                                    │
│  │  Server      │ stdio│  Session     │                                    │
│  │              │      │              │                                    │
│  │  Claude 子   │      │  接收内容    │                                    │
│  │  进程        │      │  做出反应    │                                    │
│  └──────────────┘      └──────────────┘                                    │
│                                                                             │
│  特点：                                                                    │
│  • Channel 是 Claude Code 的子进程                                         │
│  • 通过 stdio 协议通信                                                      │
│  • 内容以 <channel> 标签形式出现在对话中                                   │
│  • Claude 将其视为外部事件，自主决定如何响应                               │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│                    PTY Wrapper 方案                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌──────────────┐                                                           │
│  │  外部事件    │  用户从手机发送的消息                                     │
│  │  来源        │                                                           │
│  └──────────────┘                                                           │
│          │                                                                  │
│          ▼                                                                  │
│  ┌──────────────┐                                                           │
│  │  CC-Island   │  接收消息，转发到 Wrapper                                 │
│  │  Desktop     │                                                           │
│  └──────────────┘                                                           │
│          │                                                                  │
│          │ TCP Socket                                                       │
│          ▼                                                                  │
│  ┌──────────────┐                                                           │
│  │  PTY Wrapper │  监听 Socket，合并输入                                    │
│  │              │                                                           │
│  │  ┌────────┐  │                                                           │
│  │  │ PTY    │◄─├── 直接写入 PTY stdin                                      │
│  │  │ Master │  │                                                           │
│  │  └────────┘  │                                                           │
│  └──────────────┘                                                           │
│          │                                                                  │
│          │ PTY stdin                                                        │
│          ▼                                                                  │
│  ┌──────────────┐                                                           │
│  │  Claude CLI  │  接收输入，就像用户在终端输入一样                         │
│  │              │                                                           │
│  │  Claude 认为 │  这是用户直接输入的命令                                   │
│  │  这是用户    │                                                           │
│  │  输入        │                                                           │
│  └──────────────┘                                                           │
│                                                                             │
│  特点：                                                                    │
│  • Wrapper 是 Claude 的父进程                                               │
│  • 通过 PTY stdin 直接注入                                                  │
│  • 内容以"用户输入"形式出现                                                │
│  • Claude 将其视为用户命令，必须响应                                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
